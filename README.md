# FARMA PRO — Descargas

Sistema de gestión para farmacias y boticas del Perú.

## Descargar la última versión

Entre a **[Releases → la versión más reciente](../../releases/latest)** y descargue:

- `FARMA_PRO_Instalador_<versión>.exe` — el instalador;
- `Guia_de_instalacion_FARMA_PRO.pdf` — la guía de instalación paso a paso;
- `Manual_de_usuario_FARMA_PRO.pdf` — el manual de uso diario.

Si ya tiene FARMA PRO instalado, no necesita descargar nada: el programa avisa cuando hay una versión nueva y se
actualiza con un clic.

Requisitos: Windows 10 u 11 de 64 bits y Firebird 2.5.9 (gratuito; la guía explica cómo instalarlo).
